# Personal Finance Dashboard（Mortgage ETF Dashboard）

## 產品特色
- 📱 純前端、手機優先設計，無需帳號、無需後端，開啟即用
- 🔒 所有資料只存在你的瀏覽器 localStorage，不上傳、不追蹤
- 🏦 內建完整房貸試算引擎（等額本息／等額本金、提前還款試算；剩餘本金可選填，留空自動計算並每日更新）
- 📈 投資中心：手動輸入持有數量與價格，自動試算成本、市值、損益與報酬率
- 📊 一鍵掌握淨資產、資產配置、現金流與財務健康評分
- 👀 提供示範資料，免輸入即可體驗完整功能

## 功能介紹
- **Dashboard 首頁**：Hero Banner、Demo 模式、新手引導、資料完整度、快速新增、淨資產總覽、資產／負債概況、投資總覽、房貸概況、財務健康分析、資產配置分析、每月現金流、財務目標摘要
- **資產管理**：現金／活存、股票／ETF（含損益試算，建議改用投資中心管理）、不動產、定存、其他資產
- **📈 投資中心**（v5.0 新增）：ETF、股票、基金、REITs、債券、其他，記錄持有數量／平均成本／最新價格，自動試算投資成本、目前市值、未實現損益、報酬率（手動輸入價格，不串接任何股票／ETF API，不做即時行情）
- **負債管理**：房貸試算引擎（Mortgage Engine：等額本息／等額本金、提前還款試算；剩餘本金可選填，留空由系統自動計算並每日更新）、車貸／信貸簡易貸款追蹤、信用卡、其他負債
- **收入管理** / **固定支出**：分類記錄每月收入與固定支出
- **每月生活費**：單一數字，用於現金流估算
- **財務目標（Goals）**：淨資產、現金、ETF、定存、緊急預備金、自訂目標，含進度追蹤
- **財務健康分析**：整合分數／等級＋五項指標（負債比、儲蓄率、緊急預備金月數、房貸負擔率、目標完成率），並提供依風險排序的規則式建議
- **資產配置分析**：依資產類型統計占比，含集中度提醒
- **⚙️ 設定**：系統資訊（版本、更新日期、GitHub／README／CHANGELOG 連結）、一鍵清除所有資料
- **開發測試模式**（Developer Tools，僅供開發／驗收使用）

## 快速開始
1. 下載或 clone 本專案
2. 直接以瀏覽器開啟 `index.html`，或部署至 GitHub Pages
3. 想快速看到完整畫面效果，可在首頁點擊「👀 體驗 Demo」→「載入示範資料」
4. 準備好記錄自己的資料時，點擊「建立自己的資料」即可清空示範資料重新開始
5. 新增房貸時，若不清楚目前實際剩餘本金，可以直接留空，系統會依原始貸款金額、利率、期數、起貸日期自動推算，並每天自動更新
6. 想追蹤股票／ETF 等投資部位，建議使用「📈 投資中心」而非資產頁的「股票／ETF」類型，可記錄數量與價格並自動試算損益
7. 所有資料僅儲存在你目前瀏覽器的 localStorage，換裝置或清除瀏覽器資料需重新輸入

## localStorage Key

| Key | 用途 | 資料型態 |
|---|---|---|
| `nw_assets` | 資產清單（現金、股票／ETF、不動產、定存、其他） | Array |
| `nw_debts` | 負債清單（房貸、車貸、信貸、信用卡、其他）。房貸含 `originalAmount`（原始貸款金額）、`totalMonths`（貸款總期數）、`startDate`（起貸日期）、`repaymentMethod`（還款方式：equalPayment 本息平均攤還／equalPrincipal 本金平均攤還）、`remainingPrincipalMode`（v4.2 新增，`auto`／`manual`：留空剩餘本金即為 `auto`，由系統依 Mortgage Engine 每日自動計算並寫回 `amount`；手動輸入即為 `manual`，`amount` 永遠以使用者輸入為準；v4.1 以前建立、無此欄位的舊資料視為 `manual`）、`monthlySubsidy`（v5.1 新增，選填，每月房貸補貼金額；無此欄位的舊資料一律視為 0 元），每月應繳與已還期數改由 Mortgage Engine 自動計算，不再存於資料中。車貸／信貸維持 `monthlyPayment`（每月應繳）與 `remainingMonths`（剩餘期數）手動維護，目前尚不支援補貼欄位 | Array |
| `nw_income` | 每月收入清單 | Array |
| `nw_expenses` | 每月固定支出清單 | Array |
| `nw_living_expense` | 每月生活費（單一數字，不分類） | Number |
| `nw_goals` | 財務目標清單（含自訂目標的「目前金額」） | Array |
| `nw_onboarding_completed` | 新手引導是否已完成（按下「開始建立」後設為 true，僅供 UI 判斷是否顯示歡迎卡片，不屬於財務資料） | Boolean |
| `nw_demo_mode` | 目前畫面上的資料是否為一鍵載入的示範資料（僅供 UI 顯示 Badge／切換邏輯使用，Demo 資料實際仍寫入上述既有 key，不新增獨立的示範資料結構） | Boolean |
| `investments`（v5.0 新增） | 投資中心清單，每筆含 `type`（ETF／股票／基金／REITs／債券／其他）、`name`、`quantity`（持有數量，支援小數）、`avgCost`（平均成本）、`latestPrice`（最新價格，手動輸入）。投資成本／目前市值／未實現損益／報酬率皆為即時計算，不寫入資料。此 key 與 `nw_assets` 是兩套獨立機制，不互相同步 | Array |

## Version 5.1 更新內容（Cashflow Optimization，房貸補貼機制）
本版本改善每月現金流計算，讓房貸月付金正確納入每月支出，並支援「部分房貸由預留資金補貼」的情境（例如增貸後預留活存補貼房貸）：
- 房貸資料新增「每月房貸補貼（元，選填）」，系統自動計算補貼後的實際負擔（房貸月付金－補貼，最低 0），沿用既有 Mortgage Engine，未建立新公式
- 首頁「每月可存金額」修正為：每月收入－固定支出－生活費－所有貸款實際月負擔，並在現金流卡片新增「🏦 房貸補貼」明細（房貸月付／房貸補貼／薪資實際負擔）
- 固定支出頁與新增／編輯表單新增提示，說明房貸月付金已由負債頁自動計算並計入首頁現金流，避免與固定支出頁的房貸類記錄重複計算
- 舊資料完全相容：沒有補貼欄位的房貸一律視為補貼 0 元

## Version 5.0 更新內容（Investment Center，以 v4.2 為基礎）
本版本新增完整的投資管理模組，以「手動輸入價格」為主，不串接任何股票／ETF API，不做即時行情：
- 新增「📈 投資中心」獨立頁面與底部導覽項目，支援 ETF／股票／基金／REITs／債券／其他六種類型的完整 CRUD
- 每筆投資記錄持有數量、平均成本、最新價格，自動即時計算投資成本、目前市值、未實現損益、報酬率（皆不可手動輸入）
- 首頁新增「📈 投資總覽」卡片，加總所有投資資料
- 首頁總資產／淨資產納入投資市值：`總資產 = 既有資產總和（現金＋股票/ETF＋不動產＋定存＋其他）＋投資市值`
- 新增獨立 localStorage key：`investments`，不影響既有資料結構
- Mortgage Engine、財務健康計算、Goals 計算、Demo Mode、Onboarding 及所有 v4.2 既有功能維持不變

## Version 4.2 更新內容（Mortgage UX Improvement）
本版本改善房貸新增流程，一般使用者不需要先到銀行查詢剩餘本金即可完成新增：
- 房貸「剩餘本金」改為選填，留空時系統會直接呼叫既有 Mortgage Engine，依原始貸款金額、年利率、貸款總期數、起貸日期、還款方式自動推算，且每次開啟儀表板都會依當天日期重新計算一次，讓餘額自然遞減
- 手動輸入優先：只要有輸入剩餘本金，系統一律直接採用該數字，不會被自動計算覆蓋，適合曾提前還款、增貸或變更貸款條件的情況
- 修正手機版驗證失敗時錯誤訊息被底部按鈕遮住的問題，並加入自動捲動與 focus 至錯誤欄位

### ⚠️ 已知限制與規格判斷（重要，請詳閱）
1. **總資產公式**：v5.0 規格書提供的公式（現金＋投資＋其他資產＋房屋）省略了「定存」。為避免影響既有資產功能，實作採「既有資產總和不變＋投資市值疊加」的方式，定存仍計入總資產。
2. **與資產頁「股票／ETF」類型並存但不同步**：投資中心與資產頁既有的「股票／ETF」類型是兩套獨立機制。若同一筆持股在兩邊都輸入，首頁總資產會重複計算。目前版本維持兩者並存以維持相容性，並已在資產頁與新增／編輯表單中加入提示，引導使用者改用投資中心管理股票／ETF；是否於未來版本整合或淘汰舊有 ETF 輸入方式，留待後續評估。
3. **與淨資產相關計算不同步**：財務健康分析的負債比、資產配置分析、Goals 的「淨資產」目標進度，依規格「不可修改」維持只讀 `nw_assets`／`nw_debts`，不會納入投資市值。因此這些數字可能與首頁頂部「總資產／淨資產」不一致，屬本版本已知的設計取捨。
