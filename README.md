# Personal Finance Dashboard（Mortgage ETF Dashboard）

## 產品特色
- 📱 純前端、手機優先設計，無需帳號、無需後端，開啟即用
- 🔒 所有資料只存在你的瀏覽器 localStorage，不上傳、不追蹤
- 🏦 內建完整房貸試算引擎（等額本息／等額本金、提前還款試算）
- 📊 一鍵掌握淨資產、資產配置、現金流與財務健康評分
- 👀 提供示範資料，免輸入即可體驗完整功能

## 功能介紹
- **Dashboard 首頁**：Hero Banner、Demo 模式、新手引導、資料完整度、快速新增、淨資產總覽、資產／負債概況、房貸概況、財務健康分析、資產配置分析、每月現金流、財務目標摘要
- **資產管理**：現金／活存、股票／ETF（含損益試算）、不動產、定存、其他資產
- **負債管理**：房貸試算引擎（Mortgage Engine：等額本息／等額本金、提前還款試算）、車貸／信貸簡易貸款追蹤、信用卡、其他負債
- **收入管理** / **固定支出**：分類記錄每月收入與固定支出
- **每月生活費**：單一數字，用於現金流估算
- **財務目標（Goals）**：淨資產、現金、ETF、定存、緊急預備金、自訂目標，含進度追蹤
- **財務健康分析**：整合分數／等級＋五項指標（負債比、儲蓄率、緊急預備金月數、房貸負擔率、目標完成率），並提供依風險排序的規則式建議
- **資產配置分析**：依資產類型統計占比，含集中度提醒
- **⚙️ 設定**：系統資訊（版本、更新日期、GitHub／README／CHANGELOG 連結）、一鍵清除所有資料
- **開發測試模式**（Developer Tools，僅供開發／驗收使用）

## 快速開始
1. 下載或 clone 本專案
2. 直接以瀏覽器開啟 `index.html`，或部署至 GitHub Pages
3. 想快速看到完整畫面效果，可在首頁點擊「👀 體驗 Demo」→「載入示範資料」
4. 準備好記錄自己的資料時，點擊「建立自己的資料」即可清空示範資料重新開始
5. 所有資料僅儲存在你目前瀏覽器的 localStorage，換裝置或清除瀏覽器資料需重新輸入

## localStorage Key

| Key | 用途 | 資料型態 |
|---|---|---|
| `nw_assets` | 資產清單（現金、股票／ETF、不動產、定存、其他） | Array |
| `nw_debts` | 負債清單（房貸、車貸、信貸、信用卡、其他）。房貸含 `originalAmount`（原始貸款金額）、`totalMonths`（貸款總期數）、`startDate`（起貸日期）、`repaymentMethod`（還款方式：equalPayment 本息平均攤還／equalPrincipal 本金平均攤還），每月應繳與已還期數改由 Mortgage Engine 自動計算，不再存於資料中。車貸／信貸維持 `monthlyPayment`（每月應繳）與 `remainingMonths`（剩餘期數）手動維護 | Array |
| `nw_income` | 每月收入清單 | Array |
| `nw_expenses` | 每月固定支出清單 | Array |
| `nw_living_expense` | 每月生活費（單一數字，不分類） | Number |
| `nw_goals` | 財務目標清單（含自訂目標的「目前金額」） | Array |
| `nw_onboarding_completed` | 新手引導是否已完成（按下「開始建立」後設為 true，僅供 UI 判斷是否顯示歡迎卡片，不屬於財務資料） | Boolean |
| `nw_demo_mode`（v4.1 新增） | 目前畫面上的資料是否為一鍵載入的示範資料（僅供 UI 顯示 Badge／切換邏輯使用，Demo 資料實際仍寫入上述既有 key，不新增獨立的示範資料結構） | Boolean |

## 專案結構
```
index.html
style.css
app.js
```

單一頁面應用（SPA），純前端運作，無後端、無 API、無外部函式庫依賴，所有資料僅儲存在使用者瀏覽器的 localStorage。

## Version 4.1 更新內容（Product Polish）
本版本專注於產品質感與展示體驗，**未新增任何財務功能**，Mortgage Engine、財務健康計算、Goals 計算、所有 CRUD 與 localStorage 資料結構皆與 v4.0 完全相容：
- 首頁新增 🏠 Hero Banner，提供產品簡介與「立即開始」捲動導覽
- 首頁新增 👀 Demo 模式：一鍵載入涵蓋現金／ETF／房貸／收入／支出／Goals 的完整示範資料，並可一鍵切換回自己的資料；載入前若偵測到既有資料會先跳出確認視窗，避免誤蓋
- 新增「⚙️ 設定」區塊（位於工具頁）：系統資訊（版本、更新日期、GitHub／README／CHANGELOG 連結）與一鍵清除所有資料（附二次確認，清除後自動重新整理回到初始狀態）
- 所有頁面底部統一改為簡潔 Footer：產品名稱／版本／MIT License／GitHub 連結，取代原本的版本徽章
- 更新 README、CHANGELOG

> ⚠️ 開發者注意：`GITHUB_REPO_URL` 目前為佔位連結，請於 `app.js` 中依實際 repository 網址更新。
